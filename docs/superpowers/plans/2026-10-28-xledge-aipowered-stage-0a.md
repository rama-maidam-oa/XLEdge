# XLEdge AIPowered — Stage 0a (solution + empty projects) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `AIPowered\XLEdge\XLEdge.sln` with six new, empty, XLEdge-named projects whose project types, settings and reference graph match GLSense AIPowered 11.1.2, and which build clean in Debug and Release.

**Architecture:** Projects are written from scratch (not copied) using GLSense AIPowered as the reference design. Dependency graph is identical to GLSense: Contracts ← Shared ← Loader.Core ← {shell, Addin.Core}; Build references shell + Addin.Core. No business code, no ADX module, no NuGet packages yet — those arrive in later stages.

**Tech Stack:** classic (non-SDK) .csproj, ToolsVersion 15.0, .NET Framework 4.8.1, AnyCPU, C# `latest`, MSBuild (VS 2022 Community), `sn.exe` (NETFX 4.8.1 Tools).

**Spec:** `docs/superpowers/specs/2026-10-28-xledge-hot-swappable-core-design.md` (§1 build approach, §2 layout + project mapping, §6 deviations)
